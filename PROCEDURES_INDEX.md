## How to Use This Index

1. **Find your procedure:** Browse by category or use your browser's search function (Ctrl+F or Cmd+F)
2. **Click the link:** Navigate directly to the procedure
3. **Follow the instructions:** Each procedure includes detailed steps and safety information

## Adding to This Index

When you add a new procedure:
1. Add it to the appropriate category section above
2. Use the format: `- [Procedure Name](./path/to/procedure.md) - Brief description`
3. Keep the list alphabetically organized within each category
4. Update the category README as well

## Search Tips

- Look for keywords related to your task
- Check multiple categories if unsure
- Use related procedures as starting points
- Contact procedure authors with questions
