# Experimental Procedures

This directory contains standard operating procedures (SOPs) for experimental work.

## Available Procedures

- [Sample Preparation](./sample-preparation.md) - Guidelines for preparing samples
- Add more procedures as they are created

## Contributing

To add a new experimental procedure:
1. Create a new markdown file in this directory
2. Follow the template structure (see `/templates/procedure-template.md`)
3. Update this README with a link to your new procedure
