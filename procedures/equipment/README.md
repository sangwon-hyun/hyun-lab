# Equipment Procedures

This directory contains operating procedures and maintenance guidelines for lab equipment.

## Available Procedures

- [Equipment Maintenance](./equipment-maintenance.md) - General maintenance guidelines
- Add more procedures as they are created

## Contributing

To add a new equipment procedure:
1. Create a new markdown file in this directory
2. Follow the template structure (see `/templates/procedure-template.md`)
3. Update this README with a link to your new procedure
