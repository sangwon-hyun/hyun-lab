# Hyun Lab Procedures Repository

Welcome to the central repository for the Hyun research group's laboratory procedures. This repository serves as the organizational center for all standard operating procedures (SOPs), protocols, and guidelines used in our lab.

## 📚 Procedure Categories

### [Experimental Procedures](./procedures/experimental/)
Standard operating procedures for experimental work, including sample preparation, assay protocols, and laboratory techniques.

### [Computational Procedures](./procedures/computational/)
Workflows and guidelines for data analysis, computational methods, and bioinformatics pipelines.

### [Safety Procedures](./procedures/safety/)
Essential safety protocols, emergency procedures, and lab safety guidelines. **All lab members must read these.**

### [Equipment Procedures](./procedures/equipment/)
Operating instructions and maintenance guidelines for laboratory equipment.

## 🚀 Quick Start

1. **New to the lab?** Start with [Lab Safety Basics](./procedures/safety/lab-safety-basics.md)
2. **Looking for a specific procedure?** Navigate to the relevant category above
3. **Want to add a procedure?** See the [Contributing](#contributing) section below

## 📝 Contributing

We encourage all lab members to contribute to this repository. To add or update a procedure:

1. Use the [procedure template](./templates/procedure-template.md) as a starting point
2. Create your procedure in the appropriate category folder
3. Update the category README to include a link to your procedure
4. Ensure your procedure includes:
   - Clear purpose and prerequisites
   - Safety considerations
   - Step-by-step instructions
   - Troubleshooting guidance
   - Proper documentation

## 📋 Procedure Template

All procedures should follow the standard template located at [`/templates/procedure-template.md`](./templates/procedure-template.md). This ensures consistency and completeness across all documentation.

## 🔄 Keeping Procedures Updated

- Review your procedures regularly (at least annually)
- Update the "Last Updated" date and version when making changes
- Document changes in the Revision History section
- Notify the team when important procedures are updated

## 📖 Best Practices

- **Be specific:** Include exact measurements, times, and conditions
- **Be clear:** Write for someone unfamiliar with the procedure
- **Be safe:** Always include relevant safety information
- **Be thorough:** Include troubleshooting tips and expected outcomes
- **Be current:** Keep procedures up to date with current practices
